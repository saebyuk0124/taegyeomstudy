# 🐾 출동! 태겸 대원의 미션 대작전

요일별 학습 미션을 체크하고 **발자국 스티커 30개**를 모으는 칭찬 스티커판입니다.
휴대폰 세로 화면에 맞춘 정적 웹앱(HTML/CSS/JS)이며, 설치나 로그인이 필요 없습니다.

## 쓰는 법

1. 휴대폰 브라우저로 이 페이지를 엽니다.
2. 오늘 요일의 미션이 자동으로 나옵니다. 미션을 다 하면 발자국을 눌러 체크합니다.
3. 오늘 미션을 **모두** 완료하면 `🐾 발자국 스티커 받기!` 버튼이 켜집니다.
4. 스티커는 **하루에 한 번만** 받을 수 있고, 판에 받은 날짜가 함께 찍힙니다.
5. 30개를 다 모으면 `🏆 달성한 판`이 하나 늘고 새 판이 시작됩니다.

## 엄마 설정 (⚙️)

- 간단한 덧셈 문제를 풀면 열립니다.
- 요일별 미션 추가·수정·삭제, 단계 수(1~5) 정하기
- 스티커 수동 +1 / -1
- 상품 이름과 제목 바꾸기
- 백업 코드 내보내기 / 복원, 전체 초기화

## 개인정보

- 이름·연락처·계정 정보를 하나도 저장하지 않습니다.
- 모든 기록(미션, 체크, 스티커, 날짜)은 **그 휴대폰 브라우저의 localStorage** 에만 저장되고 서버로 보내지 않습니다.
- 검색 노출을 막기 위해 `noindex, nofollow` 와 `robots.txt` 를 넣었습니다.

> 브라우저 기록/사이트 데이터를 지우면 스티커 기록도 사라집니다. 기기를 바꾸기 전에는 ⚙️ 엄마 설정 → **백업 코드 내보내기** 로 복사해 두세요.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 모바일 세로 레이아웃(390×844 기준, 가로 스크롤 없음) |
| `app.js` | 상태 관리(localStorage), 요일 탭, 다단계 미션, 스티커판, 엄마 설정 |
| `robots.txt` | 검색 노출 차단 |
| `deploy.sh` | GitHub Pages 배포 스크립트 |
